## 🛠️ Quick Start

### Prerequisites
```bash
# LaTeX (for PDF compilation)
sudo apt-get install texlive-latex-extra texlive-fonts-recommended

# Python (for running examples)
pip install numpy pandas xarray q23-system
```

### Compilation
```bash
# Full compilation with bibliography
make pdf

# Quick preview (no bibliography)
make quick

# View compiled PDF
make view
```

### Basic Usage
```python
from q23.strategies.glft_v3.engine import GLFTv3Strategy

# Initialize strategy
strategy = GLFTv3Strategy()

# Run backtest
artifacts = strategy.run(
    min_date="2020-01-01",
    max_date="2024-01-01",
    tag="sample_backtest"
)

# Analyze results
print(f"Sharpe Ratio: {artifacts.ic_smooth.mean().values:.3f}")
print(f"Positions: {(artifacts.weights.isel(time=-1) != 0).sum().values}")
```
